About this project

This is a road network planning and traffic congestion prediction tool built for Nairobi, Kenya, as a class project exploring graph algorithms, traffic modelling and urban data visualisation.

It loads real road networks from OpenStreetMap, computes routes with Dijkstra and A*, predicts congestion by time of day, animates a vehicle simulation, and lets you save and compare scenarios — all in the browser, no installation required. It's built for Nairobi but works with any OpenStreetMap location.

Built by John Omanga as a class project (SWE-IST 4900).
